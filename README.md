# سامانه هوشمند مدیریت و تنظیم پیش‌نویس قرارداد

نسخه اولیه رابط کاربری فارسی و راست‌چین مبتنی بر Next.js.

## اجرای محلی

پیش‌نیاز: Node.js 20 یا بالاتر.

```bash
npm install
npm run dev
```

سپس آدرس http://localhost:3000 را باز کنید.

## ساخت نسخه Production

```bash
npm run build
npm start
```

## استقرار

مخزن را به Vercel متصل کنید. Framework روی Next.js شناسایی می‌شود و Build Command برابر `npm run build` است.

## وضعیت فعلی

این نسخه رابط کاربری اولیه و داشبورد نمایشی را فراهم می‌کند. داده‌های صفحه آزمایشی هستند و هنوز دیتابیس، ورود واقعی، API قراردادها، لینک امن اشخاص و امضای دیجیتال به آن متصل نشده‌اند.

این محصول مستقل و غیررسمی است و وابستگی یا نمایندگی سازمان ثبت اسناد و املاک کشور یا قوه قضاییه را ادعا نمی‌کند.
